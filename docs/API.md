# API Documentation

## Market Data Endpoint
- **Source**: `MarketDataService` (see `src/services/market-data-service.ts`).
- **Payload**: `{ timestamp, binanceBtcUsdt, bithumbBtcKrw, krwPerUsdt }`.
- **Usage**: consumed by `StrategyEngine` to compute kimchi premium.

## Execution Plans
- Generated by `ExecutionEngine` (`src/core/execution-engine.ts`).
- Structure mirrors `ExecutionPlan` interface from `src/domain/models.ts`.

## Monitoring API
- `DashboardApi.getState()` returns `{ positions, metrics }` for UI/telemetry.
- Integrate via HTTP controller layer if exposing externally.
